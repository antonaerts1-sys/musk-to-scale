# Wealth, to scale: Elon Musk

Elon Musk's fortune drawn to scale: one pixel is $1,000. Scroll sideways through $816.9 billion (Forbes Real-Time, 25 November 2026) and see what it could pay for.

All figures and their sources are in `data.js` and listed at the end of the page.

Inspired by [Wealth, shown to scale](https://mkorostoff.github.io/1-pixel-wealth/) by Matt Korostoff (2020). This is a new implementation; no code was reused.
